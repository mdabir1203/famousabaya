AbaYa Track — Quick Start
==========================

FIRST TIME ONLY (do once per PC):
  1. Install Node.js 18+ from https://nodejs.org  (choose LTS)
  2. Double-click:  install\INSTALL.bat
     - Enables Yarn (via corepack), installs PnP dependencies, creates Desktop shortcut.
     - No internet needed for yarn install — packages are bundled in .yarn\cache.
  3. Edit .env in this folder if you use Cloudflare:
       CF_WORKER_URL=https://abaya-track.YOURNAME.workers.dev
       CF_INGEST_SECRET=your_shared_secret
     Leave .env unchanged if you are running local-only (no cloud sync).

EVERY DAY — start the software:
  Double-click "AbaYa Track" on your Desktop.
     Opens the factory server, the kiosk tab, and the dashboard tab.
  (Alternative: double-click  install\LAUNCH-ALL.bat)

BARCODE CATALOG SETUP (do this before first launch):
  Open .env in Notepad and set:
    CATALOG_XLSX_PATH=C:\Users\DELL\Desktop\barcode\items_export.xlsx
  Replace the path with the actual location of your items_export.xlsx file.
  The server loads it automatically at startup and refreshes it every 24 hours.

  Your Excel file needs these columns:
    - Barcode Display Name  — the unique barcode for each item variant
    - Item Category         — the work type (must match exactly: Tailor (01), etc.)
    - Item Name             — optional description shown on kiosk cards
    - Tier                  — optional grade: Standard, Premium, Luxury, Plain Abaya
  Full format guide: docs\CATALOG_EXCEL_SPEC.md

CATALOG SYNC via folder watcher (office PC, optional):
  1. Copy  tools\catalog-watcher\config.example.json
       to  tools\catalog-watcher\config.json
  2. Edit the paths and ingestSecret in config.json.
  3. From then on, LAUNCH-ALL.bat starts the watcher automatically.
  4. Drop items_export-style .xlsx files into your watchDir to update the catalog.
     Full guide: docs\OFFICE_LAPTOP.md

OPEN IN BROWSER MANUALLY (on-site / factory PC):
  Kiosk:     http://localhost:3000/kiosk.html
  Dashboard: http://localhost:3000/dashboard.html
  Tablet QR: http://localhost:3000/setup

LIVE CLOUD URLS (after running cloudflare/DEPLOY.ps1):
  CEO Dashboard: https://farewellabaya.com
  Kiosk (HTTPS):  https://kiosk.farewellabaya.com/kiosk.html
  Dashboard:      https://kiosk.farewellabaya.com/dashboard.html
  (Replace 3050 with PORT from .env if you changed it.)

DEPLOY KIOSK TO TABLETS (10+ tablets, multiple factories):
  1. Start the server (LAUNCH-ALL.bat opens the setup page automatically).
  2. On the setup page, enter each factory name and tablet count.
  3. Click "Generate QR Codes" then "Print All".
  4. On each tablet: scan QR with camera → opens kiosk → Add to Home Screen.
  Guide: docs\DEPLOYMENT_KIOSK_FINGERPRINT.md
