## What changes for the operator (dashboard)

The Live Active Sessions card on the CEO Dashboard right column now
shows:

```
                                    02:14:32            ← green, ticks every 2.5s
                                    active today · Button
                                    42h 02m 03s         ← amber, ticks every 2.5s
                                    this build
```

- The **"active today · `<ProcessName>`"** cell is back at the top of
  the right column. v1.2.18 added it, then a v1.2.19-prep pass had
  dropped it by mistake. Restored.
- The **"last finished"** cell is removed from the live card. The
  data is still computed (`lastFinishMsByEmpId`,
  `lastFinishDisplayMs`, `fmtTimeOfDay`, `fmtDateShort`,
  `fmtDateLong`) because the per-employee / per-abaya report reads
  it — operators want to spot a worker who re-tapped Start
  immediately after a 10-second Finish from the report, not from
  the live board.
- The **"this build"** cell now shows this session's elapsed time
  on this abaya (`serverNowMs - startedMs`), ticking every 2.5s.
  Was previously the wall-clock build age (aggregated across
  sessions, 24h-gap rule) which read as "1218h 9m 42s · started
  Jul 13" for a single active session — confusing. The aggregate
  total is still on the Daily / Weekly / Monthly / Yearly reports.
