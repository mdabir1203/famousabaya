# v1.2.21 — Remove broken catalog-watcher from install

**Release date:** 2026-09-04
**Type:** patch (install-coherence fix)
**Builds on:** v1.2.20

---

## What this release fixes

v1.2.20 was supposed to be the "all-in-one install works on a
fresh laptop" release. The cert was correctly applied, the
factory-deps were correctly bundled, the .env.production template
was correctly materialized. But the launcher's Watcher Log showed
a fresh install crash on every boot:

```
[launcher] Started catalog watcher
C:\Program Files\AbaYa Track Launcher\resources\tools\catalog-watcher\.pnp.cjs:6771
    throw firstError:
```

The catalog-watcher's `.pnp.cjs` (Yarn PnP manifest) and
`.yarn/cache/` are gitignored — they only exist on the dev box.
The CI build had no PnP data, the install shipped without it,
the launcher detected `config.json` and tried to start the
watcher, and the PnP loader crashed.

This crash was latent in v1.2.19 too, but the v1.2.19 install
hit "PM2 NOT INSTALLED" before the watcher could crash, so
operators never noticed.

## The fix

Removed the `tools/catalog-watcher` extraResources entry
entirely. The catalog-watcher is an office-side tool (used for
the LAN photo sync + cloud-watcher demo), not a factory tool.
The launcher's ecosystem config already gates the watcher on
`config.json` existing — without the bundled watcher directory,
the gate is false, the watcher PM2 app is never added, no crash.

If a factory operator ever needs the watcher:

```powershell
# From the operator's local dev checkout
Copy-Item -Recurse "tools\catalog-watcher" `
  "$env:APPDATA\AbaYa Track\resources\tools\catalog-watcher"
# Then add a PM2 app pointing at watch-catalog.js manually
```

(Not currently supported — would need the watcher's own
`.factory-deps`-style bundle step, or a switch to a
node-modules linker. Out of scope for v1.2.21.)

- The factory sees "WATCHER LOG → throw firstError" on every
  install. The watcher is not factory-required, so just
  upgrade to v1.2.21.
- The factory's auto-updater detects v1.2.21 → installs
  automatically (cert is stable, doom loop stays dead).
- The dev box wants to verify the cert. After installing
  v1.2.21:
  ```powershell
  Get-AuthenticodeSignature "C:\Program Files\AbaYa Track Launcher\AbaYa Track Launcher.exe"
  ```
  should show `Subject=CN=AbaYa Track Self Signed`,
  `Thumbprint=F91A8848B57AF4DC5D545AB2E8757F0847E53E3F`.
